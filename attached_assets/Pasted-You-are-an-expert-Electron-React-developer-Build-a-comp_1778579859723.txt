## CORE FEATURES TO BUILD

### 1. PACKAGE DISCOVERY

In `electron/handlers/pipHandler.js`:
- Run `pip list --format=json` to get all installed Python packages
- Run `pip show <package>` to get metadata (version, location, dependencies)
- Detect all virtualenvs by scanning common paths:
  (~/.virtualenvs, ./venv, ./env, ./.venv)
- Detect conda environments via `conda env list --json`

In `electron/handlers/npmHandler.js`:
- Run `npm list -g --json --depth=0` for global npm packages
- Detect nvm-managed node versions via `nvm ls` or scanning ~/.nvm/versions/
- Run `npm list --json --depth=0` in detected project directories

In `electron/handlers/envScanner.js`:
- Return a unified environment list:
  [{ id, name, type: 'pip'|'venv'|'conda'|'npm'|'nvm', path, packages: [] }]

### 2. VERSION CHECKING

In `electron/handlers/versionChecker.js`:
- For each pip package: call `https://pypi.org/pypi/{package}/json`
  and extract `info.version` as latest
- For each npm package: call `https://registry.npmjs.org/{package}/latest`
  and extract `version` as latest
- Compare installed vs latest using semver:
  - Same → status: 'up-to-date'
  - Patch diff → status: 'patch'
  - Minor diff → status: 'minor'
  - Major diff → status: 'major'
- Batch API calls with concurrency limit of 5 to avoid rate limiting
- Cache results in SQLite for 6 hours

### 3. SMART GROUPING

In `src/lib/groupTags.js`:
Define a mapping object:
{
  'ML / AI': ['torch', 'tensorflow', 'numpy', 'scikit-learn', 'transformers',
              'keras', 'xgboost', 'lightgbm', 'opencv-python', 'pillow',
              'huggingface-hub', 'diffusers', 'accelerate', 'datasets'],

  'Data': ['pandas', 'matplotlib', 'seaborn', 'plotly', 'polars',
           'scipy', 'statsmodels', 'sqlalchemy', 'pyarrow', 'openpyxl'],

  'Web': ['flask', 'fastapi', 'django', 'requests', 'httpx', 'aiohttp',
          'uvicorn', 'gunicorn', 'starlette', 'express', 'axios',
          'cors', 'dotenv', 'nodemon'],

  'Dev Tools': ['pytest', 'black', 'mypy', 'flake8', 'pylint', 'isort',
                'pre-commit', 'eslint', 'prettier', 'jest', 'ts-node',
                'typescript', 'webpack', 'vite'],

  'Others': [] // catch-all
}
- Any package not in above lists → 'Others'
- User can manually reassign a package to a different group
  (persist in SQLite table: user_tags)

### 4. COMPATIBILITY WARNING ENGINE

In `src/lib/compatMatrix.js`:
Define known breaking pairs:
{
  warnings: [
    {
      package: 'torch',
      targetVersionMin: '2.0.0',
      requires: { package: 'numpy', minVersion: '1.26.0' },
      message: 'PyTorch 2.x requires numpy >= 1.26.0'
    },
    {
      package: 'tensorflow',
      targetVersionMin: '2.13.0',
      requires: { package: 'numpy', minVersion: '1.23.0' },
      message: 'TensorFlow 2.13+ requires numpy >= 1.23.0'
    }
    // add more as needed
  ]
}

Before executing any update:
- Loop through selected packages
- Check compatMatrix for each package being updated
- If a dependency package is installed at a lower version than required,
  show CompatWarning dialog with:
  - What will break
  - Suggested fix (update dependency first)
  - Option: "Auto-fix order" (reorders update queue correctly)
  - Option: "Update anyway" (with red warning)
  - Option: "Cancel"

### 5. SAFE UPDATE MODE

In Zustand store (`usePackageStore.js`):
- State: `safeMode: true` (default)

Behavior when safeMode is ON:
- Automatically select only 'patch' status packages for "Update All"
- Show 'minor' and 'major' packages with a lock icon
- Clicking a locked package shows: "Safe Mode is ON. This is a MAJOR update.
  Disable Safe Mode or update manually."
- SafeModeToggle component in header — toggle with confirmation dialog
  when switching to Full Mode

### 6. SNAPSHOT SYSTEM

In `electron/handlers/snapshotHandler.js`:

createSnapshot(envId):
- For pip/venv/conda envs: run `pip freeze > snapshot_<timestamp>.txt`
- For npm: copy current package.json + package-lock.json
- Save snapshot metadata to SQLite:
  { id, envId, name, timestamp, filePath, packageCount }
- Auto-trigger before any bulk update

restoreSnapshot(snapshotId):
- For pip: run `pip install -r <snapshot_file>`
- For npm: run `npm install` with restored package.json
- Show restore progress same as update progress view

In `src/pages/Snapshots.jsx`:
- List all snapshots grouped by environment
- Each snapshot card shows: name, date, package count, env name
- Buttons: "Restore", "Download", "Delete"
- "Create Manual Snapshot" button at top

### 7. UPDATE EXECUTION ENGINE

In `electron/handlers/pipHandler.js` and `npmHandler.js`:

updatePackage(packageName, targetVersion, envPath):
- Run `pip install <package>==<version>` or `npm install <package>@<version>`
- Stream stdout/stderr back to renderer via IPC events:
  ipcMain.emit('update:progress', { package, percent, status, message })

In `src/components/UpdateProgress.jsx`:
- Listen to IPC events via window.electronAPI.onUpdateProgress
- Show per-package card:
  [ Package Name ]  [ ████████░░ 80% ]  [ Installing... ]
- Status values: 'queued' | 'installing' | 'done' | 'failed'
- On 'failed': show error reason in a collapsible section (not raw CLI dump)
- Post-update summary modal:
  "X packages updated successfully. X failed. X skipped."
- Cancel button: kills active child_process

### 8. HISTORY & AUDIT LOG

SQLite table `update_history`:
  id, package_name, ecosystem, env_name,
  from_version, to_version, status, error_message, updated_at

In `src/pages/History.jsx`:
- Table view with columns: Package, Ecosystem, From, To, Status, Date
- Filter by: date range, ecosystem, status (success/failed)
- Export as CSV button
- Click row → expand to show full error if failed

## DATABASE SCHEMA

In `database/schema.sql`:

CREATE TABLE packages (
  id INTEGER PRIMARY KEY,
  name TEXT, ecosystem TEXT, env_id TEXT,
  installed_version TEXT, latest_version TEXT,
  status TEXT, group_name TEXT, last_checked INTEGER
);

CREATE TABLE environments (
  id TEXT PRIMARY KEY,
  name TEXT, type TEXT, path TEXT, is_active INTEGER
);

CREATE TABLE snapshots (
  id INTEGER PRIMARY KEY,
  env_id TEXT, name TEXT, file_path TEXT,
  package_count INTEGER, created_at INTEGER
);

CREATE TABLE update_history (
  id INTEGER PRIMARY KEY,
  package_name TEXT, ecosystem TEXT, env_name TEXT,
  from_version TEXT, to_version TEXT,
  status TEXT, error_message TEXT, updated_at INTEGER
);

CREATE TABLE user_tags (
  package_name TEXT PRIMARY KEY,
  group_name TEXT
);

CREATE TABLE version_cache (
  package_name TEXT PRIMARY KEY,
  ecosystem TEXT, latest_version TEXT, cached_at INTEGER
);

## IPC BRIDGE (preload.js)

Expose the following via contextBridge as `window.electronAPI`:

{
  // Discovery
  scanEnvironments: () => ipcRenderer.invoke('scan:environments'),
  getPackages: (envId) => ipcRenderer.invoke('packages:get', envId),

  // Version
  checkVersions: (packages) => ipcRenderer.invoke('versions:check', packages),

  // Updates
  updatePackage: (pkg, version, envPath) =>
    ipcRenderer.invoke('update:package', pkg, version, envPath),
  updateBatch: (packages, envPath) =>
    ipcRenderer.invoke('update:batch', packages, envPath),
  cancelUpdate: () => ipcRenderer.invoke('update:cancel'),
  onUpdateProgress: (cb) =>
    ipcRenderer.on('update:progress', (_, data) => cb(data)),

  // Snapshots
  createSnapshot: (envId) => ipcRenderer.invoke('snapshot:create', envId),
  restoreSnapshot: (snapshotId) =>
    ipcRenderer.invoke('snapshot:restore', snapshotId),
  getSnapshots: () => ipcRenderer.invoke('snapshot:list'),

  // History
  getHistory: (filters) => ipcRenderer.invoke('history:get', filters),
  exportHistory: () => ipcRenderer.invoke('history:export'),
}

## ERROR HANDLING RULES

- All child_process calls wrapped in try/catch
- If pip not found: show setup guide modal
  ("Python not detected. Install Python or set custom path in Settings.")
- If npm not found: similar guide for Node.js
- Network failure on version check: use cached version if available,
  else show "Unable to check — offline?" badge
- Permission errors on update: show
  "Permission denied. Try running PackageGuard as administrator."
- Never crash the app on package error —
  mark that package as 'failed' and continue
