# 🛡️ Package Guard

Official Windows Installer Hosting Repository for Package Guard.

## 📥 Download Windows Installer

Download the official Windows installer (`.exe`) directly from the Releases page:

- **Official Release**: [Package Guard v1.0.0](https://github.com/nsakthivel-dev/Package-Guard/releases/tag/v1.0.0)
- **Direct Installer Download**: [PackageGuard-Setup.exe](https://github.com/nsakthivel-dev/Package-Guard/releases/download/v1.0.0/PackageGuard-Setup.exe)

### System Requirements
- **OS**: Windows 10 / Windows 11 (64-bit)
- **Architecture**: x64

### Installation
1. Download `PackageGuard-Setup.exe`.
2. Run the installer and follow the on-screen instructions.
3. For silent automated deployment (e.g. Microsoft Store / Enterprise), standard NSIS silent installation is supported:
   ```cmd
   PackageGuard-Setup.exe /S
   ```
